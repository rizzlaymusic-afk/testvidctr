# Requirements

This is a sanitized requirements template for a new Rust + WASM UI project. It preserves core functional and non-functional requirements while removing project-specific editorial content.

## Key Requirements (summary)
- Local-first scanning and matching workflow
- Clear separation between discovery and apply operations
- Robust backup and changelog policy (never delete files)
- Developer docs must include architecture, standards, testing, and security guidance
- Performance and reliability targets: non-blocking scans, throttled progress updates
