# Init Template

This is a sanitized bootstrap template for creating workspace-level instructions and agent initialization prompts. Use this to guide initial onboarding for a new project.

## Key Steps
1. Discover existing conventions and important files.
2. Generate or merge workspace instruction files (`.github/copilot-instructions.md`, `AGENTS.md`).
3. Run an initial scan and create a baseline.
4. Document the bootstrapping steps in a `BOOTSTRAP.md` file.
