This is a sanitized template for creating workspace instruction files. It preserves the original intent (recording conventions, backup rules, and changelog discipline) while removing project-specific editorial notes.

## Template highlights
- Record workspace conventions clearly and concisely.
- Prefer a workspace-local backup convention for new projects.
- Do not delete files — move deprecated docs to `bin/`.
- Update changelog and document every edit.
